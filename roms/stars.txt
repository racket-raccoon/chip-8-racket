Non-default setup for stars.ch8

Use the Super-CHIP 1.1 profile:

  fx1e-sets-vf?            = #f
  load-store-increments-i? = #f
  logic-ops-clear-vf?      = #f
  shifts-use-vy?           = #f
  jump-uses-vx?            = #t

And change the execution speed:

  opcodes/second = 1800

Why: this C8P Super-CHIP 1.1 demo expects FX55/FX65 to leave I unchanged.
With the current #t setting, the star data is read from the wrong addresses
and the display is reduced to a few stray pixels. Super-CHIP's database
default is 30 opcodes per 60 Hz frame (1800 per second).
