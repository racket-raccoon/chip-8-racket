Setup for stars.ch8

Use the SUPER-CHIP 1.1 (quirks only) preset (1800 opcodes/second).

This C8P SUPER-CHIP 1.1 demo expects FX55/FX65 to leave I unchanged. With an
incrementing memory mode, star data is read from the wrong addresses and the
display is reduced to a few stray pixels. The preset also uses SUPER-CHIP's
database default of 30 opcodes per 60 Hz frame.
