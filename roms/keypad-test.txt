Setup for keypad-test.ch8

Use the SUPER-CHIP 1.1 (quirks only) preset (1800 opcodes/second). Speed is
not functionally important for this static test screen, so 600 is also usable.

This is Hap's SUPER-CHIP keypad test. In particular, it expects 8XY6/8XYE to
shift VX in place. With "Shift instructions use VY" enabled, opcode 8206 copies
V0 into V2 first, corrupting the test's control state and eventually making the
emulator execute sprite data as an opcode.
